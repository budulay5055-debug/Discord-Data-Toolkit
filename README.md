🛠️ Discord-Data-Toolkit (Cwelium)
Bu proje, Discord verilerini yönetmek, proxy yapılandırmalarını test etmek ve API etkileşimlerini otomatize etmek için geliştirilmiş kapsamlı bir Python aracıdır.

👾 Özellikler
Proje aşağıdaki temel işlevleri destekler:
Token Yönetimi: Geçerli tokenları kontrol eder ve formatlar. 
Proxy Desteği: HTTP ve HTTPS proxy'lerini destekler. 
Otomasyon Araçları: Joiner, Leaver, Spammer ve Reaction özellikleri içerir. 
Gelişmiş Terminal Arayüzü: 29 farklı renk temasıyla özelleştirilebilir log sistemi sunar.

📋 Gereksinimler
Çalıştırmak için şu kütüphanelere ihtiyaç duyar:
colorama ve colorist 
requests 
tls-client 
websocket-client

📥 Kurulum ve Kullanım
Bağımlılıkları yükleyin:
Bash
pip install -r requirements.txt

Programı başlatın:

Bash
python Cwelium.py
